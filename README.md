# Codes for reconstructing the angular dependence of gap function with fork-tip STM
 
The [Julia](https://julialang.org/) codes for reconstructing the phase and the magnitude of the gap function as a function of angle can be found in the Jupyter notebook `fitting_basic_small_modulation_with_mask.ipynb`.

The directory `exported_data` contains some example plots generated by the Jupyter notebook.
